# UX Principles

ReviewTrix should follow a premium SaaS design philosophy.

---

# 1. One Primary Action

Every screen should contain exactly one primary call-to-action.

Never present multiple competing buttons.

Correct:

```

Continue

```

Avoid:

```

Continue
Import
Skip
Configure

```

---

# 2. Progressive Disclosure

Do not expose advanced settings immediately.

Show only what merchants need right now.

Advanced configuration should remain hidden behind:

"Customize"

or

"Advanced Settings"

---

# 3. Automatic Detection

ReviewTrix should continuously monitor setup progress.

Examples:

Theme Extension enabled

↓

Automatically complete checklist item

Import completed

↓

Automatically mark completed

Email automation configured

↓

Automatically update progress

Merchants should never click:

"Mark Complete"

---

# 4. Positive Language

Avoid negative empty states.

Instead of:

"No Reviews"

Use:

"Your first review is closer than you think."

Instead of:

"Nothing configured"

Use:

"Let's finish preparing your store."

---

# 5. Visible Progress

Display a circular progress indicator.

Example:

Getting Your Store Ready

82%

Every completed action updates instantly.

---

# 6. Motion

Use subtle animations.

Allowed:

- fade
- scale
- slide
- shimmer
- progress transitions

Avoid flashy animations.

Motion should communicate completion.
