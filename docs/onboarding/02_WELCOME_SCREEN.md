# Welcome Screen

The Welcome screen should create excitement without overwhelming merchants.

No settings should appear here.

---

# Layout

```

ReviewTrix green wordmark (shared OnboardingShell brand)

Turn happy customers
into your biggest marketing asset.

Collect, moderate, and display product reviews for {shop}.

✓ Collect reviews after fulfillment
✓ Display trusted widgets on your storefront
✓ Import existing reviews in minutes
✓ Setup takes about 2 minutes

[Storefront-style sample review card]
  avatar · name · Verified · stars · title · body · photos

[Get Started]

Skip for now

```

The wordmark also appears on every other onboarding screen via
`OnboardingShell` for consistent branding.

---

# Illustration

Show one realistic sample review card (not floating collage):

★★★★★ (green)

Customer avatar + Verified badge

Title, body, optional photo thumbs

Keep it compact under the checklist.

---

# Animation

Logo fades in.

Headline slides upward.

Primary button gently scales.

Illustration floats slowly.

---

# CTA

Primary:

Get Started

Secondary:

Skip for now

Skipping onboarding should immediately open the dashboard.

A setup reminder should remain visible until required tasks are complete.

---

# Design Notes

Large spacing.

Minimal text.

Single column.

Center aligned.

No cards.

No forms.

The welcome screen should communicate confidence immediately.
