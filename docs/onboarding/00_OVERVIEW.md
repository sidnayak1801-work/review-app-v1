# ReviewTrix Merchant Onboarding v2

## Vision

ReviewTrix should deliver a premium onboarding experience that feels native to Shopify while matching the polish of modern SaaS products like Shopify, Stripe, Linear, Notion and Vercel.

The onboarding should never feel like a setup wizard.

Instead, it should feel like ReviewTrix is intelligently preparing the merchant's store and guiding them toward publishing their first reviews with as little effort as possible.

---

## Core Objectives

The onboarding experience should:

- Take less than 3 minutes
- Require minimal manual configuration
- Auto-complete steps whenever possible
- Reduce merchant anxiety
- Guide merchants toward their first successful review collection
- Feel smooth, modern and premium

The merchant should never wonder:

> "What should I do next?"

Every screen should answer exactly one question.

---

# Merchant Journey

```

Install ReviewTrix

↓

Welcome

↓

Personalize Experience

↓

Store Health Check

↓

Launch Checklist

↓

Celebration

↓

Dashboard

```

Unlike traditional onboarding, ReviewTrix should not force merchants through numbered steps.

Instead, merchants should complete a dynamic launch checklist that automatically updates as ReviewTrix detects completed actions.

---

## UX Philosophy

The onboarding should emphasize:

- Momentum over configuration
- Progress over forms
- Automation over manual confirmation
- Delight over documentation

Every completed task should feel rewarding.

Animations should reinforce progress without becoming distracting.

---

## Required Setup

Required:

- Theme App Extension enabled

Recommended:

- Configure Review Requests

Optional:

- Import Reviews
- Customize Branding

Merchants may skip optional tasks and return later.

---

## First Impression

The first 60 seconds determine whether merchants trust the product.

Every screen should communicate:

- simplicity
- confidence
- professionalism

Avoid technical language whenever possible.

Instead of:

"Enable Theme App Extension"

Prefer:

"Show reviews on your storefront"

Only introduce technical terminology when merchants need to interact with Shopify.
