# Review App

## Vision

Build the most developer-friendly and merchant-friendly review platform for Shopify.

The application should provide merchants with a complete customer review solution that is easy to install, highly customizable, performant, and scalable.

The long-term goal is to become a competitive alternative to Judge.me while introducing modern AI-powered features and a superior user experience.

---

# Problem

Merchants need social proof.

Most review applications solve the basic problem but often become expensive, difficult to customize, or overloaded with unnecessary complexity.

This application focuses on:

- Simple setup
- Beautiful widgets
- High performance
- Excellent developer experience
- AI-assisted merchant tools
