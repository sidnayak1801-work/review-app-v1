# Dashboard UI Specification
## ReviewX Merchant Dashboard
Version: 1.0
Status: MVP
Target: Shopify Admin Embedded App
Framework: React + Shopify Polaris + App Bridge

---

# Objective

Build a dashboard that immediately feels like a premium SaaS application.

The dashboard should be as visually polished as products like:

- Stripe
- Linear
- Vercel
- Notion
- Shopify Admin
- Clerk
- Raycast

The merchant should understand the health of their review system within **10 seconds** of opening the app.

The interface must be beautiful without sacrificing simplicity.

This is NOT a generic admin dashboard.

This should feel like a product merchants enjoy using.

---

# Design Principles

Every design decision must satisfy these principles.

## 1. Minimal

Only show information that matters.

Never overload the screen.

White space is a feature.

---

## 2. Premium

Cards should feel expensive.

Spacing should be intentional.

Typography should be clean.

Animations should be subtle.

Nothing should look like Bootstrap.

Nothing should look autogenerated.

---

## 3. Fast

Merchants should never wonder where something is.

Navigation should be obvious.

Primary actions should always be visible.

---

## 4. Shopify Native

Respect Shopify Polaris.

Extend Polaris.

Do NOT fight Polaris.

The dashboard should feel native inside Shopify.

---

# Cursor Implementation Instructions

You are not creating a prototype.

You are implementing production-ready React components.

Requirements:

- Follow Shopify Polaris best practices.
- Use reusable, modular components.
- Keep business logic separate from presentation.
- Support light and dark mode where feasible.
- Ensure responsive behavior.
- Use semantic HTML.
- Use TypeScript where available.
- Optimize rendering performance.
- Do not introduce unnecessary dependencies.
- Match this specification exactly unless a deviation clearly improves usability.

Before considering the dashboard complete, review the implementation against every section of this specification and refine any area that falls short of a polished, premium SaaS experience.
